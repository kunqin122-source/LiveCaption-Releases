# LiveCaption Windows 实时字幕

英语语音实时转为中文字幕，供多台 Windows 中控电脑独立使用。
此仓库只提供测试发行包、公开签名更新信息和说明，不包含应用项目源码。

## 安装与使用

到 [Releases](https://github.com/kunqin122-source/LiveCaption-Releases/releases) 下载
`LiveCaption-Windows-版本号.zip`，完整解压后运行 `InstallLiveCaption.exe`。
支持 Windows 10/11 x64，无需安装 Python。各电脑分别选择自己的麦克风，点击开始。
本地离线识别与翻译不需要 API 充值，不上传直播声音，不在电脑之间分享字幕。

此为公开测试发行，尚未配置 Authenticode 代码签名。请核实下载来源与 SHA-256，
先在每台电脑验证麦克风、现场英文讲话和实际延迟，再用于正式直播。

## 统一更新

0.1.5起内置公开更新地址和发布公钥，首次需要完整安装此版本。
启动约20秒、此后每30分钟检查。下载在后台进行，连续空闲15秒后安装；
字幕、录音、麦克风测试、回放或发布窗口运行时不会重启。可关闭自动更新。
离线电脑下次运行联网补更。不承诺同一秒同步，不安装额外常驻服务。

Ed25519 验签、压缩包与成员 SHA-256 验证、启动失败回滚和坏版本隔离均在客户端执行。
未变化的模型不会重下；运行库或模型变化时只下载对应包，组内只替换实际变化的文件。
`program-*`、`runtime-*`、`models-*` ZIP 是更新器数据，不是手工安装包。
GitHub可访问性及速度取决于各电脑所在网络，网络故障不影响本地翻译。
